## 1 · 采集高 / 采集低

原来两行文字放在同一个 `NSTextField` 里，菜单自定义视图高度不足时第二行会被裁掉，看起来像「要点一下才出现采集低」。阶段五改成 `TodayRangeView`：两行各自是独立的单行标签，右侧固定一个 `?`。

问号的悬停说明（`toolTip`）与点击弹出的说明使用同一份文字：

- 采集高：本机今天（北京时间 00:00 起）实际采到的所有分钟报价中的最高值；采集低为同一批报价中的最低值。
- 同一分钟内多次刷新，也记录该分钟出现过的最高价与最低价。
- 只统计本应用运行、联网且来源报价有效时采到的数据；不含启动前、断网、休眠或未运行期间，不是交易所完整当日最高/最低。
- 跨北京时间零点自动清空，从当天第一个有效报价重新开始。
- 预警规则里的「创新高 / 创新低」也用这个基准。

菜单跟踪期间 AppKit 有可能抑制视图级 tooltip，因此问号同时支持点击弹出同一份说明；悬浮窗里以悬停为主。

## 2 · 银行显示的两套逻辑

- 国内组默认只显示偏好设置「通用 → 行情与菜单栏 → 显示品种」选中的那家银行；选中伦敦金/纽约金/美元指数这类非国内品种时回退到工商银行。顺序为 **默认银行 → 其余两家（保持原有固定顺序）**，由纯函数 `MenuBankPresentation.primary` / `domesticOrder` 决定，并有独立自测覆盖。
- 改「显示品种」时 `SettingsModel.onMenuBankChange` 触发 `setupMenu()` 重建菜单，默认那家、另外两家和展开按钮的位置一起跟着变；重置 `showOtherBanksOnce` 让新菜单回到默认状态。
- 默认银行下方常驻一个自定义视图按钮「显示其余银行金价」。点击后本次菜单会话内展开，标题变为「隐藏其余银行金价」，可再点收起。菜单关闭后再次打开时 `menuWillOpen` 把 `showOtherBanksOnce` 清零，恢复只显示默认那家；切换时调用 `NSMenu.update()` 让跟踪中的菜单立即重排隐藏项。
- 偏好设置 → 通用 → 行情与菜单栏里的「菜单栏常显示其余银行金价」写入 `UserDefaults`，开启后三家常显示、展开按钮隐藏。
- 只显示一家时不标「最低」，因为三家都可见才有横向比较的意义；完整悬浮窗仍始终显示三家。

### 展开按钮为什么改成自绘

`NSButton` 的属性字符串方案（`attributedTitle` + `attributedAlternateTitle` + `contentTintColor`）在菜单项高亮/焦点态会被 `NSButtonCell` 接管前景色，点击后仍会变回黑色。最终改为 `BlueLinkButton`（继承 `NSButton` 以保留菜单里的点击与 hitTest 行为），**重写 `draw(_:)` 自己用 `NSColor.controlAccentColor` 画文字**，不调用 `super.draw`，因此普通态、高亮态、点击后、切换标题后颜色都只由这一处决定，恒为蓝色；同时 `refusesFirstResponder = true` 避免焦点环。`setLinkText` 更新文字后 `needsDisplay = true` 强制重绘。

## 3 · 新高 / 新低提醒

### 判定口径

对每个被勾选的品种、每个方向独立维护「今日采集高/低」。当前有效报价高于此前采集高即为新高，低于此前采集低即为新低。第一个有效报价只建立基准，不提醒；跨北京时间零点重置；休市、延迟或失败缓存不参与判定。

### 确认采用的防打扰逻辑

**首报即时 + 冷静期合并汇总 + 幅度门槛 + 方向独立**：

1. 首次突破且相对上次报过的价位达到最小变动幅度（默认 0.1%），立即提醒 1 条，写明前纪录、当前价与涨幅。
2. 随后进入冷静期（默认 5 分钟）：期间每次再创新高只累计次数和最新纪录，不逐条弹窗。
3. 冷静期结束时，若期间有新纪录，合并成 1 条汇总：刷新次数、本轮累计幅度、起止价与最新价；然后开启新的冷静期窗口继续累计，不再重复「首报」。
4. 若整整一个冷静期都没有新纪录，视为本轮结束并回到空闲；之后再破纪录会重新立即首报。
5. 新高与新低分别开关、分别计时、互不抑制；方向反转时另一方向照常立即首报。

门槛以「上次对外报过的价位」（`anchor`）为基准，而不是以不断抬高的今日采集高为基准，所以缓慢单边连涨不会被 0.1% 门槛永久挡住。`record` 仍跟随今日采集高/低，用于判断是否真的刷新纪录。

配置项在 **预警规则 → 今日新高 / 新低提醒**：两个独立开关、冷静期（3/5/10/15 分钟）、最小变动幅度（0.05/0.1/0.3/0.5%）、品种多选（默认仅工商银行）。两个开关默认关闭，属于主动开启的功能。

### 与现有系统的衔接

`ExtremeAlertEngine.evaluate` 是纯函数，输入行情、今日历史、配置与状态，输出事件与新状态。App 层把旧规则事件与新事件合并后调用 `AlertEngine.routeAll` 走同一套免打扰路由：免打扰期间只记录、结束后汇总一条；其余事件继续走系统通知中心 / 非模态浮层 / Bark。冷静期状态单独存到 `UserDefaults` 的 `extremeAlertStateJSON`，损坏时从空状态开始，不影响原有规则 JSON。

## 4 · 交互与外观

- 提醒面板改为可成为 key window 的 `NSPanel`，「知道了」设为默认按钮（`\r`）；本地按键监听在提醒面板为 key window 时截获 Return/Enter，每次只关闭一个窗口并让下一个成为 key window。窗口出现时短暂激活应用以接收按键，不弹出 Dock 图标。设置窗口获得焦点时不会抢走回车。
- 状态栏不再设置系统图标，标题从 `Au xxx` 改为 `🧱 xxx`，涨跌幅与延迟色保持不变；品种名仍在悬停提示里。
- 「显示其余银行金价」在普通态与高亮态都显式使用带 `.controlAccentColor` 的属性字符串，并阻止按钮成为第一响应者，点击切换成「隐藏其余银行金价」后仍是蓝色。

## 4.1 · 提醒带电脑本地时间

`Models/AlertTimeStamp.swift` 是纯函数：用**电脑当前时区的公历**，把 `Date` 格式化为 `MM-DD hh:mm:ss`（日期用短横线，时分秒用半角冒号），需要年份时前缀 `YYYY-MM-`。

App 层 `alertTimeLine(_:)` 在 `acceptEngineResult` 里对每条**实际发出**的提醒生成一行时间戳，放在正文首行；同一批事件共用同一个触发时刻。判定规则是 `includesYear(lastDay:now:)`：偏好里记录的上次提醒日期（`lastAlertLocalDay`）与当前本地日期不同就带年份，并把新日期写回。因此：

- 当天第一条 → `2026-11-10 20:15:30`；当天后续 → `11-10 20:15:30`。
- 过本地 0 点后的第一条 → 重新带年份（日期键变化）。
- 重启应用后当天第一条不会重复带年份（日期键持久化在偏好里）。
- 免打扰期间 `recordOnly` 只记日志、不生成时间戳也不消耗「第一条」，实际推送时才生成。

因为时间戳统一加在 `acceptEngineResult` 计算出的 `body` 上，系统通知横幅、应用内浮层、Bark 三条渠道拿到的是同一份带时间的文案；Bark 测试推送也走同一套。时间戳放在正文首行而不是末尾，避免系统横幅截断时看不到时间；浮层正文框相应加高到可容纳多一行。

## 4.2 · 汇总箭头与 Bark 分组

- 冷静期满的汇总提醒标题按方向区分：`⤴ 持续创新高` / `⤵ 持续创新低`。原来两个方向都用 `⤴`，新低方向不符合直觉，改为配对的向下弯箭头；首次破纪录的「今日新高/新低」标题不变。`cleanText` 只替换涨跌 emoji，不影响这两个符号，因此 Mac 通知和 Bark 里都能正常显示。
- Bark 的分组用 query 参数 `group`。`BarkLinkParser.groupedQuery(_:)` 是纯函数：保留用户链接里的原有参数（`level`、`call` 等），剔除任何已有的 `group`（大小写不敏感），再追加 `group=Gold%20Monitor`。`BarkNotificationService.send` 无条件用它拼接 URL，所以预警、汇总、免打扰补发、目标顺延、Bark 测试推送全部归入「Gold Monitor」。持久化的原始链接不改写，设置页预览也不变。
- 自测覆盖：无参数/空参数、`level`+`call` 保留、已有 `group` 被覆盖且不重复、解码后分组名确为 `Gold Monitor`；以及两个方向汇总标题的箭头。

手动验收建议：

1. 打开菜单，确认采集高、采集低两行都在，悬停/点击 `?` 能看到口径；悬浮窗同样检查。
2. 把「显示品种」依次改成民生、浙商、工行，每次打开菜单都应默认只显示对应那家、展开按钮就在它下方；改成伦敦金应回退到工商银行。点展开按钮出现另外两家，关掉再开恢复默认；开启偏好开关后三家常显示；点完按钮标题变「隐藏其余银行金价」仍是蓝色。
3. 在预警规则页打开「创新高」，把品种设为工行，等价格刷新纪录：应收到首报；持续上涨时 5 分钟内不刷屏、期满收到一条汇总。关闭「创新高」后不再提醒。
4. 触发任意提醒窗口后连按 Enter，每次只关一个，直到全部关完；期间在偏好设置里按回车不应误关提醒。
5. 状态栏显示 `🧱` 开头，不再有 `Au` 与旧图标。
6. 连续触发两条提醒，核对 Mac 弹窗与 Bark 推送正文首行都有本地时间，第一条带年份、第二条不带；隔天再触发一条重新带年份；「显示其余银行金价」切换后仍是蓝色。
7. 等冷静期满的汇总提醒，确认创新高是 `⤴`、创新低是 `⤵`；在 Bark 里确认所有推送（含测试推送）都归在「Gold Monitor」分组。

## 已知取舍

- 提醒窗口需要接收键盘事件，因此弹出时会激活本应用（配件型应用不显示 Dock 图标）。若正在前台全屏输入，会有一次焦点切换；避免打扰优先时可在通知页关闭系统通知外的提醒渠道。
- 新高/新低只看本机采集到的报价，跨日或长时间休眠后基准从当天第一条重新开始，不补报停机期间的历史新高。
- 冷静期状态保存在 `UserDefaults`；极端情况下（强制结束进程）可能丢失最近一个窗口的计数，重启后按当天采集高低重新建立基准。
