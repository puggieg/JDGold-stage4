# JDGold · 阶段五：采集高低口径、银行显示与新高/新低提醒

在阶段四（国内溢价与当日迷你走势）基础上，完成九项交互与提醒改进：采集高/低同时显示并带口径问号、菜单栏银行显示的两套逻辑、今日新高/新低提醒（含防打扰汇总）、回车关闭提醒窗口、状态栏改为 🧱，以及提醒带电脑本地时间戳、展开按钮保持蓝色；另让菜单栏默认银行跟随「显示品种」。
保持 macOS 12 最低运行目标、Swift Package Manager、build.sh、AppKit 菜单/悬浮窗与 SwiftUI 设置；没有第三方依赖。详细设计见 [docs/STAGE5.md](docs/STAGE5.md)。

**验证范围：本机 macOS 双架构编译、签名与 `37/37` 项核心自测通过；界面行为（悬停说明、菜单展开、通知回车）仍需在你的 Mac 上按下方清单实机验收。**

基于 [PiaoyangGuohai1/GoldPrice（JDGold）](https://github.com/PiaoyangGuohai1/GoldPrice) 二次开发，保留上游署名。上传工程未包含原 LICENSE，保留方式见 [NOTICE.md](NOTICE.md)。

## 怎么生成 App 或 Unix 文件

解压后在终端输入 `cd `，把 **JDGold-stage5 文件夹**拖进去，按回车。先退出旧 JDGold，再执行：

```bash
chmod +x build.sh
./build.sh && open ./JDGold.app
```

脚本先编译、运行核心自测，再在**工程目录**生成新 App；失败时不输出新产物，不直接替换应用程序中的旧版。
优先复制你已有的 JDGold 外壳，保留 Bundle ID、图标、Info.plist 版本和原资源，以便延续旧偏好和钥匙串。原外壳在其他位置时：

```bash
./build.sh --app-shell "/你的实际路径/JDGold.app"
```

确认旧规则、Bark、溢价和走势正常后，退出新 App，再将它拖入应用程序替换；保留旧 App 副本便于回退。
没有完整 Xcode 也能构建，需要 CLT 的 Swift 5.7+ 与包含 SMAppService 的 macOS 13+ SDK，最低运行系统仍为 macOS 12。缺工具时执行 `xcode-select --install`。

只要可替换的 Unix 可执行文件：

```bash
./build.sh --binary-only
./JDGold --selftest
```

工程根目录的 **JDGold** 就是产物，不能只编译 main.swift。退出旧 App 后，将其拖入原 App 的 `Contents/MacOS/`，替换同名文件，再执行：

```bash
codesign --force --deep --sign - "/Applications/JDGold.app"
codesign --verify --deep --strict "/Applications/JDGold.app"
open "/Applications/JDGold.app"
```

### 阶段五新增功能

**采集高 / 采集低**：菜单和悬浮窗里两行各自独立显示，不会再被裁成一行。右侧 `?` 悬停（或点击）说明口径：本机今天（北京时间 00:00 起）采到的分钟报价最高/最低值，同一分钟多次刷新也会记录期间高低，不含启动前、断网、休眠时段，不是交易所完整日线，跨零点重置。

**国内积存金显示**：菜单默认只显示偏好设置「显示品种」选中的那家银行（若选的是国际品种或美元指数，国内组没有对应银行，回退到工商银行）；改这个设置会立即重建菜单，默认那家、其余两家和展开按钮位置一起跟着变。默认那家下方的「显示其余银行金价」只对本次打开的菜单生效，关掉再开恢复只显示默认那家；偏好设置 → 通用 → 「菜单栏常显示其余银行金价」则持久生效。只显示一家时不标「最低」。展开按钮在普通态、点击后与菜单高亮态都保持蓝色（自绘文字，不交给系统按钮状态接管）。

**今日新高 / 新低提醒**（预警规则页顶部）：新高、新低两个独立开关，默认关闭；品种可多选，默认仅工商银行。采用确认过的防打扰逻辑：

1. 首次破纪录且相对上次报过的价位达到幅度门槛（默认 0.1%）→ 立即 1 条，含前纪录、现价、涨幅。
2. 之后进入冷静期（默认 5 分钟）→ 再创新高只静默累计次数与最新价。
3. 期满合并 1 条汇总（刷新次数、本轮累计幅度、最新价），随后继续新窗口，不重复「首报」。
4. 一整个冷静期没有新纪录 → 视为本轮结束，之后再破纪录重新首报。
5. 新高与新低分别计时、互不抑制，跨北京时间零点重置，沿用免打扰/系统通知/Bark。

冷静期与门槛可调：`3/5/10/15` 分钟、`0.05/0.1/0.3/0.5%`。详见 [docs/STAGE5.md](docs/STAGE5.md)。

**提醒带本地时间**：Mac 弹窗（系统通知横幅与应用内浮层）和 Bark 手机推送的正文首行都带触发时的**电脑本地时间**。当天第一条为 `YYYY-MM-DD hh:mm:ss`（例如 `2026-11-10 20:15:30`），当天后续为 `MM-DD hh:mm:ss`（例如 `11-10 20:15:30`）；日期用短横线、时分秒用半角冒号；过本地 0 点后的第一条重新带年份。按电脑当前时区的公历分日，「上次提醒日期」写入偏好，重启应用也不会把当天第二条误当成第一条；免打扰期间只记录不发，实际发出时才生成时间戳。

**汇总提醒的方向标志**：冷静期满的汇总提醒用方向箭头区分——持续创新高是 `⤴ 持续创新高`，持续创新低改成 `⤵ 持续创新低`（原来新低也用 `⤴`，不符合直觉）。首次破纪录的「今日新高/新低」标题不变。

**Bark 分组**：本程序发出的所有推送（含测试推送）都会自动带上 `group=Gold Monitor`，在 Bark 里集中到「Gold Monitor」文件夹。用户链接里已有的 `group` 参数会被覆盖，`level`、`call` 等原参数保留；持久化里保存的仍是原始链接，不会改写。

**交互细节**：应用内提醒窗口支持按 Enter/Return 一次关闭一个，连按依次关完；状态栏改为 `🧱 价格 涨跌幅`，不再有 `Au` 和旧图标；「显示其余银行金价」点击后变成「隐藏其余银行金价」，两种状态与菜单高亮态都保持蓝色。

### 国内溢价

对三家银行分别计算：

`国际折算价（元/克）= 伦敦金（美元/盎司）× USD/CNY ÷ 31.1035`

`溢价（元/克）= 国内积存金价 − 国际折算价`

`溢价百分比 = 溢价 ÷ 国际折算价 × 100`

显示格式：`溢价 +X.XX 元/克（+Y.Y%）`，负溢价按负号显示；菜单与完整悬浮窗均显示，迷你模式选择国内品种时也显示溢价。
悬停说明其含义、未计交易费用及当前采用汇率的来源时间。这一参考差额有助于理解相对贵便宜，不是可直接套利的利润。

汇率取新浪在岸 USD/CNY 当前价。新接口真实响应和字段核对见 [verification/FX_API.md](verification/FX_API.md)。
汇率失败、过期、明显未来时间或无效数字时隐藏溢价；国内价或伦敦金缺失/过期也隐藏。不会用 0、USD/CNH、昨收或失败缓存拼出错误数字。
金价与汇率均按各自来源时间核查，仍可能存在不同步，tooltip 保留汇率时间。

### 当日迷你走势

- **北京时间分日**，与中国市场和现有来源时间展示保持一致；跨日立即隐藏旧线并自动清空本地当天文件。
- 每品种每分钟最多一条：保留分钟内最新采集价，并同时保存该分钟高低价，避免高频刷新造成文件膨胀或遗漏已观察的高低。
- 菜单中每品种都有迷你线；完整悬浮窗各行显示线和“采集高/低”。图用 **NSBezierPath** 绘制，不使用 Swift Charts；迷你模式保持简洁，不显示走势。
- 平盘画水平线，只有一个样本画一个点；无样本显示“今日暂无采样”，高低显示 `—`。断网后保留已采集线并变灰；不会把失败缓存采成新的点。缺口超过相邻两个分钟桶时断线，不连成连续行情。
- “采集高/低”包含分钟内已观察价格，**不包含启动前、断网或休眠期间**，不是交易所完整当日最高/最低。数据源时间过期时跳过新采样。
- 数据保存在 `~/Library/Application Support/<原 Bundle ID>/today-prices.json`；不改规则 UserDefaults。常规每分钟至多写盘一次，下一分钟带上上一分钟最终数据；正常退出异步补写，最多等两秒。强制结束或保存失败可能缺最后一分钟的采样。
- 同日重开恢复样本；损坏文件移到同目录备份后从空记录开始，备份失败则暂停写盘保留原件。写盘失败仍显示内存采样，并输出统一日志。
- 完整悬浮窗采用滚动内容区域，小屏或显示器断开后仍可查看全部品种；保留固定、关闭、鼠标穿透和位置恢复。

## 我该怎么手动验证

1. **先构建**：运行 `./build.sh`，应看到 `37/37 项通过` 后生成 App。打开新 App 核对旧规则、Bark、状态栏品种、刷新间隔，并退出重开检查。
2. **溢价**：网络正常且三项来源都及时有效时，三家国内报价下显示溢价；对照伦敦金与 tooltip 中的汇率，用公式手算一行。迷你模式选择国内品种也应显示；国际品种不显示国内溢价。
3. **采样**：完整悬浮窗和菜单先显示点，再等跨过下一分钟应有线和采集高低。频繁手动刷新不会增加同分钟记录数。这里的高低只覆盖本机实际采到的报价。
4. **降级**：断网后立即刷新，应保留旧价、走势变灰，溢价隐藏；恢复后等待失败退避到期，有效来源恢复则再显示。任意来源已延迟时该行溢价可能继续隐藏，这是有效性保护。
5. **重启与跨日**：从菜单正常退出、同日重开，走势应恢复；跨北京时间午夜后昨日线和高低清空，随后从新日第一点开始。无需改系统时间，跨日逻辑也有固定输入测试覆盖。
6. **布局**：浅色、深色各检查一次；完整/迷你切换；在小屏或第二显示器断开后，完整模式可滚动查看最后一行，固定/关闭/穿透恢复仍有效。
7. **故障边界**：汇率无效、缺失/过期、存储损坏、分钟去重、缺口和极值用共享自测验证，不需要破坏你的真实数据来测试。
8. **阶段五 · 采集高低**：打开菜单，确认「采集高」「采集低」两行同时可见；悬停（或点击）右侧 `?` 应看到完整口径；悬浮窗同样检查。
9. **阶段五 · 银行显示**：偏好设置把「显示品种」改成民生银行，打开菜单应默认只显示民生、展开按钮就在民生下方；再改成浙商、工商银行各试一次；改成伦敦金时应回退到工商银行。点「显示其余银行金价」出现另外两家，关掉菜单再打开恢复只显示默认那家；在偏好设置打开「菜单栏常显示其余银行金价」后三家常显示。点完展开按钮后按钮标题变「隐藏其余银行金价」，确认仍是蓝色。
10. **阶段五 · 新高新低**：在预警规则页开启「创新高时提醒」（品种默认工行），待价格刷新纪录应收到首报；持续上涨时冷静期内不刷屏、期满收到一条汇总；关闭开关后不再提醒。两个方向分别开关验证互不干扰。
11. **阶段五 · 交互**：触发提醒窗口后连按 Enter，每次只关一个直到全部关完；状态栏显示 `🧱` 开头且不再有 `Au` 与旧图标。
12. **阶段五 · 时间戳与配色**：触发两条提醒，确认 Mac 弹窗与 Bark 推送正文首行都有本地时间；当天第一条是 `YYYY-MM-DD hh:mm:ss`、后续是 `MM-DD hh:mm:ss`（时分秒用半角冒号）。隔天（或过了本地 0 点）再触发一条，应重新带年份；重启 App 后当天第一条不应重复带年份。「显示其余银行金价」点击变成「隐藏其余银行金价」后仍是蓝色。
13. **阶段五 · 汇总箭头与 Bark 分组**：等冷静期满收到汇总提醒，确认持续创新高是 `⤴`、持续创新低是 `⤵`；在 Bark 里确认所有推送（含「发送测试推送」）都归在「Gold Monitor」分组，而不是默认信息列表。
